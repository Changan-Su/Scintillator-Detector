# Notes 2026-02-26 · Pandas / Histo10_Cubic 知识点

## 1. DataFrame 索引与清洗

- **iloc**：按整数位置选取，和列名无关。`df.iloc[:, :9]` = 所有行、前 9 列。
- **dropna(subset=[...])**：按缺失值删行。`subset` 指定只在哪些列检查 NaN，这些列有缺失才删该行。
- **astype(type)**：把某列转成指定类型，如 `df["Face"].astype(int)`。

## 2. 类型注解（Type Hints）

- `df_event: pd.DataFrame`：参数类型注解，表示参数应为 DataFrame。
- `-> pd.DataFrame`：返回值类型注解。
- 不参与运行，仅给人和 IDE/类型检查用。

## 3. groupby 与聚合

- **groupby(列名)**：按列分组，相同键的行在一组。
- **as_index=False**：分组键保留为普通列，不变成行索引。
- `df.groupby(["Face","j","k"], as_index=False)["PhotonCount"].sum()`：按 (Face,j,k) 分组，对 PhotonCount 求和。

## 4. aggregate_for_heatmap 中的 agg

- **agg**：按 (Face, j, k) 聚合后的 DataFrame。
- 列：`Face`, `j`, `k`, `Count`（Count = 该格子所有事件的 PhotonCount 之和）。
- 一行一个格子，用于后续 6 个 4×4 热力图。

## 5. pd.DataFrame 是什么

- **二维表**：行 + 列，有列名，可带行索引。
- **内存中的数据结构**，不是文件格式；可与 CSV/Excel 等互相转换（read_csv / to_csv 等）。

## 6. DataFrame 常用属性

| 属性/写法 | 含义 |
|----------|------|
| `df.shape` | 形状 (行数, 列数)，如 `(1000, 9)` |
| `df.columns` | 列名，如 `Index(['EventID','Face',...])` |
| `df.index` | 行索引，默认 0, 1, 2, ... |
| `df["列名"]` | 取一列，得到 Series |
| `df[["A","B"]]` | 取多列，得到 DataFrame |
| `df.iloc[行, 列]` | 按整数位置取，如 `df.iloc[0:10, :]` 前 10 行 |
| `df.head(n)` | 前 n 行 |
| `df.empty` | 是否为空表 |

## 7. np.ndarray 是什么

- **NumPy 的 N 维数组**：多维、同类型数值的容器（如 1D 向量、2D 矩阵）。
- 与 list/DataFrame 区别：同类型、适合数值计算；`build_face_matrix` 返回的 4×4 矩阵就是 ndarray，供 `imshow` 画热力图。
- 常用：`np.zeros((4,4))`、`arr.shape`、`arr[i,j]`。

## 8. 布尔索引（按条件筛行）

- **`df[df["列"] == 值]`**：只保留该列等于指定值的行。
- 例如 `face_df = agg[agg["Face"] == face]`：从 agg 里筛出当前面（face）的所有格子行，得到该面的子表。

## 9. for 解包与 `_`

- **`for _, row in df.iterrows():`**：解包时第一个值（行索引）不用，用 `_` 占位；只要第二个值 `row`（该行数据）。
- **`_`**：约定俗成的“不关心”的变量名，表示该值在循环里不会用到。

## 10. iterrows()

- **`df.iterrows()`**：按行遍历 DataFrame，每次得到 `(index, row)`，`row` 是该行的 Series（列名→值）。
- 用途：逐行取 `row["列名"]` 做处理。行多时较慢，可用向量化替代；本脚本每面最多 16 行，用 iterrows 没问题。

## 11. if __name__ == "__main__"

- **`__name__`**：当前模块的内置变量。直接运行该 .py 时为 `"__main__"`，被 import 时为模块名（如 `"Histo10_Cubic"`）。
- **`if __name__ == "__main__": main()`**：只有用 `python Histo10_Cubic.py ...` 直接运行脚本时才执行 `main()`；被 import 时不会自动跑，便于既当脚本又当模块复用。
